# Odirico OS

Odirico OS is a workflow platform designed for infrastructure, design, and QA/QC operations.

It provides tools for managing tickets, tracking production, organizing teams, and improving project execution.

## Features

- Role-based dashboards (PM, QC, Designer, Client)
- QA/QC ticketing system
- Project and team management
- Customizable workspace settings
- Admin controls for organizations

## Tech Stack

- Next.js
- TypeScript
- Supabase
- Vercel
- Cloudflare
